# Aviation Accident Analysis

## Project Overview
For this project I analyzed avaiation accident data from 1983 to 2023.The goal was to help an airline insurer identify the safest airplane makes and models based on injury rates and destruction rates.

## Findings
- Large planes tend to be safer than small planes overall.
- Boeing 777 and Boeing 757 had the lowest injury rates among large planes.
- Cessna 172 was the standout safest small plane.
- Accidents in bad weather (IMC) are much more dangerous than those in good weather(VMC)
- Planes with more engines tend to have lower injury rates.
